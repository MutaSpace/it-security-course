# GitHub Portfolio Privacy Checklist

- [ ] Remove passwords, tokens, keys, secrets, recovery codes, and flags.
- [ ] Remove grades, Canvas screenshots, private instructor feedback, and student records.
- [ ] Remove real internal IP addresses, hostnames, organization diagrams, and unapproved findings.
- [ ] Crop screenshots so unrelated browser tabs, notifications, usernames, and file paths are not visible.
- [ ] Replace real data with fictional or sanitized sample data.
- [ ] Confirm every image, document, and repository file is approved for public posting.
- [ ] State that the work was completed in an authorized learning environment.
- [ ] Credit public sources and use your own explanation.
- [ ] Ask the instructor before publishing anything that may be sensitive.
