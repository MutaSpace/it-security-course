# Course Lab Troubleshooting Guide

## 1. Read the exact error
Copy the full message into private notes. Do not publish credentials or private paths.

## 2. Confirm the environment
Check the required operating system, virtual machine, snapshot, network mode, account, and tool version.

## 3. Verify the basics
Confirm filenames, capitalization, permissions, paths, IP configuration, and whether the required service is running.

## 4. Change one thing at a time
Record the original state, make one controlled change, test, and note the result.

## 5. Preserve evidence
Capture the error, the command or setting, the correction, and the validation result.

## 6. Ask for help safely
Provide the mission name, goal, expected result, actual result, exact error, and steps already attempted. Contact Professor Chidinma Agwu at chidinma.agwu@hccs.edu or through Canvas.
