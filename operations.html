Course description

Security for hardware, software, networks, and data.

Instruction includes physical security, backup procedures, relevant tools, encryption, protection from malicious software, and the operational practices used to reduce and respond to risk.

The course follows the CompTIA Security+ knowledge areas but reorganizes them around realistic security work.

Learning outcomes

By the end of the course, you should be able to:

01

Explain security concepts

Apply confidentiality, integrity, availability, authentication, authorization, non-repudiation, zero trust, and control categories.

02

Analyze threats and vulnerabilities

Recognize threat actors, attack techniques, indicators, vulnerabilities, and appropriate mitigations.

03

Design secure architecture

Use segmentation, secure protocols, data protection, resilience, and recovery concepts.

04

Perform security operations

Harden systems, manage access, monitor activity, investigate evidence, and respond to incidents.

05

Evaluate risk and governance

Build risk registers, support policies, evaluate third parties, and communicate with leadership.

06

Document professional work

Create a GitHub Pages portfolio containing sanitized evidence, reports, diagrams, and reflections.

Course workflow

Each mission moves through the same four stages.

Online students can complete the same sequence asynchronously using the scenario, guided material, technical operation, and debrief prompts provided in Canvas and this course hub.

01

Brief

Understand the scenario, goal, scope, evidence, and rules of engagement.

02

Learn

Study the concepts and watch or read the assigned support material.

03

Operate

Perform the lab, collect evidence, validate results, and note remaining risk.

04

Document

Submit through Canvas and add an approved, sanitized version to GitHub Pages.

Rules of engagement

Use security knowledge only with authorization.

Course activities must remain inside the assigned lab scope. Stop and contact the instructor when authorization or safety is unclear.

01

Stay in scope

Use only instructor-approved accounts, systems, networks, data, and tools.

02

Protect privacy

Remove personal information, credentials, grades, and restricted details from public work.

03

Preserve evidence

Capture the original state before making changes whenever the scenario requires it.

04

Explain impact

Connect every action to confidentiality, integrity, availability, risk, and business needs.
