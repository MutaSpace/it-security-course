# Information Technology Security Course Site

This is a static, interactive course website designed for GitHub Pages. It uses only HTML, CSS, and JavaScript.

## Instructor information

- Professor Chidinma Agwu
- chidinma.agwu@hccs.edu
- Students may email or send a message through Canvas.

## Important course behavior

- The website contains no assignment dates.
- Canvas is the official location for announcements, schedules, grading, feedback, and submissions.
- Interactive progress is stored in the current browser using localStorage.
- The public website does not collect student information or send progress to the instructor.
- Students create a GitHub account and a GitHub Pages portfolio for approved project documentation.

## Publish with GitHub Pages

1. Create or open the GitHub repository for the course website.
2. Upload every file and folder in this directory to the repository root.
3. Do not upload only the ZIP file. Extract it first.
4. Open repository Settings, then Pages.
5. Select Deploy from a branch, choose `main`, and choose `/(root)`.
6. Save and open the published Pages address after deployment completes.

The root should include `index.html`, the other page files, `styles.css`, `app.js`, `.nojekyll`, and the `downloads` folder.

## Local preview

Run a local web server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Main pages

- `index.html` - course home and personal dashboard
- `operations.html` - mini syllabus and course guide
- `missions.html` - filterable sixteen-mission library
- `mission-01.html` through `mission-16.html` - complete hands-on mission pages
- `portfolio.html` - GitHub Pages portfolio center
- `tracker.html` - interactive assignment tracker and CSV export
- `practice.html` - original Security+ style practice questions
- `resources.html` - filterable downloads and external learning resources
- `404.html` - custom error page

## Included interactive features

- Browser-saved mission and assignment progress
- Searchable and filterable mission dashboard
- Downloadable progress CSV export
- GitHub Pages portfolio URL storage on the current device
- Portfolio privacy and publication checklists
- Security+ practice questions with explanations and saved best score
- Searchable resource library with direct course downloads and curated official links
- Light and dark themes plus responsive mobile navigation

## Course records and privacy

Canvas remains the official source for section announcements, schedules, assignment instructions, grades, feedback, and submissions. The public site does not collect student accounts, grades, or submissions. Browser progress is stored only on the current device using localStorage.
